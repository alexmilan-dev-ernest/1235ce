2.1 · Idea i disseny d’una botiga virtual

MP1235 · Comerç electrònic · Recursos interactius del tema

Cas transversal: Impuls. Una botiga d'accessoris per entrenar a casa, orientada a principiants amb poc espai. Cada laboratori aplica una decisió del tema 2.1; consulta el dossier per a les explicacions i exemples resolts.

1. Laboratori de buyer persona

Construeix un perfil útil per prendre decisions comercials. Escriu necessitats i objeccions concretes, no adjectius genèrics.

Completa els camps i justifica la decisió.

2. Proposta de valor i competència

Redacta una promesa que relacioni públic, necessitat, solució i diferència. Després compara-la amb alternatives.

Completa els quatre components.

3. Simulador de marge comercial i punt mort

Modifica les dades i comprova com canvia la viabilitat. Els costos s'introdueixen sense IVA deduïble; l'exemple no incorpora transport ni publicitat variable.

Calcula el marge i el punt mort.

Escull les pàgines que ha de tenir la botiga. Revisa si el client pot trobar un producte, comprar-lo i resoldre incidències.

Selecciona les pàgines.

6. Detecta friccions de compra

Selecciona la mesura que millor resol cada problema del recorregut.

Un client descobreix despeses d'enviament només al final.
El comprador no sap si una banda és adequada per a principiants.
El formulari obliga a crear un compte abans de pagar.
Tria una resposta per situació.

7. Pla de prova d’usabilitat

Prepara una prova amb tasques observables. Evita preguntes genèriques com “T'agrada la web?”.

Defineix una tasca, una evidència i una possible millora.
